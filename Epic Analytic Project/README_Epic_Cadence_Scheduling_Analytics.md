# Epic Cadence Scheduling Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end healthcare analytics workflow
modeled after an Epic Cadence scheduling environment. The objective was
to analyze appointment scheduling, provider performance, patient flow,
and operational efficiency using SQL, Excel, and Power BI.

------------------------------------------------------------------------

## Business Problem

Healthcare organizations need visibility into scheduling performance,
patient wait times, provider workload, and appointment outcomes to
improve patient access and clinic efficiency.

This dashboard was designed to answer questions such as:

-   Which providers have the highest appointment volume?
-   How long are patients waiting?
-   Which departments are busiest?
-   What is the appointment completion rate?
-   Where are scheduling bottlenecks?

## Project Workflow

1.  Designed and queried a healthcare scheduling database in MySQL.
2.  Validated and cleaned the SQL output.
3.  Exported datasets to Excel worksheets.
4.  Imported Excel data into Power BI.
5.  Built interactive dashboards.
6.  Generated operational insights and recommendations.

## Key Insights

-   40 appointments analyzed.
-   10 active providers.
-   67.5% appointment completion rate.
-   Average patient wait time: 14.56 minutes.
-   Average visit length: 25.52 minutes.
-   Primary Care had the highest appointment volume.

------------------------------------------------------------------------

## Business Recommendations

-   Reduce patient wait times through schedule optimization.
-   Implement appointment reminders to reduce no-shows.
-   Monitor provider workload for balanced scheduling.
-   Continue tracking operational KPIs through interactive dashboards.
